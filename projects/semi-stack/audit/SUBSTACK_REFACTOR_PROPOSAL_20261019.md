# SEMI STACK 하위 분류 재설계 초안 v0.1 — 2026-10-19

## 원칙
- **원본 20개 F01~F10, B01~B10 보존.** 아래 목록은 하위 STACK *제안*이며 전체 309개 기업-공정 배치의 검증이 끝난 확정 결과가 아니다.
- 구조: `공정(20개) → 가공대상/독립 기능(substack) → 납품 역할[장비/소재/부품/인프라/서비스] → 실제 제품 → 회사`.
- `기술 키워드`(ALD, 레이저, 3D), `적용 시장`(HBM, DRAM, NAND, AI)과 `동인`(신규 CAPEX, 양산 램프)은 별도 속성/PLAY이며 불필요한 정식 노드 증식을 피한다.
- **판매 제품 존재 ≠ STACK 정식 배치 승격.** 주 매출 세그먼트는 Primary 1곳, Secondary는 원래 합의한 섹터별 매출비중 게이트 X%와 source/confidence 필요. 수치가 없을 땐 검토 큐. 자동 승격 금지.
- 동일 장비의 부수 기능(절단 장비 내부 세척·비전 검사)을 근거로 세정 F08·검사 B08에 추가 배치하지 않는다. 별도 독립 판매 제품/사업과 매출기여를 확인한다.
- 피어 비교는 공정명 일치보다 `수주 결정요인·고객공정·매출 연동` 유사성을 우선. 기업은 복수 하위 제품을 제공할 수 있으므로 기업명으로 배타적인 substack을 만들지 않는다.
- 6개 삼성증권 SEMI 관심종목 그룹(S01~S06)은 그대로 두고 SBT의 `@#` 소제목만 더 세분화하는 안이다. POP SBT 산출물 변경은 QA 후.

## 한미반도체(042700) 배치 사고 분석
- 원장에 2026-10-18 `B04/B05/B08` 3곳으로 추가·유지된 상태.
- [2025 사업보고서(2026-03-12) KIND](https://kind.krx.co.kr/external/2026/03/12/002053/20260312004659/11011.htm):
  - `HBM TC BONDER`: 핵심 상용화. **B05.TC본딩 제품 역할 확인**, 전사 내 최대 매출 위치는 별도품목 수치가 없어 정성 추정.
  - `micro SAW & VISION PLACEMENT (MSVP)`: 패키지 절단→세척→건조→비전검사→선별·적재 일괄 공정. **B04.패키지·패널 싱귤레이션 제품 역할 확인**. 회사는 해당 제품 세계 점유율 1위 주장(독립 시장조사 수치 아님).
  - **micro SAW W(Wafer SAW)** 등 모델도 상용화 목록에 존재. 따라서 웨이퍼 절단 제품은 `제품 존재` 확인이나 해당 모델의 실매출 비중과 피어 대표성은 **검토 대기**. 한미가 오직 패키지 쏘만 한다는 단정 금물.
  - `6-SIDE INSPECTION`: 별도 상용 검사장비, B08.HBM 6면 검사 제품 확인. 그러나 별도 매출비중은 미공시.
  - `하이브리드 본더`는 개발 중이라고 명시. B05.Hybrid Bonding 매출 실현으로 계산 금지.
  - 공시의 2025년 매출 범주는 `반도체 제조용 장비 외` 84.62%, `Conversion Kit 등` 15.38%이며 위 3개 장비 **개별 매출액 분리는 불가**.
  - MSVP에 세척·검사 기능이 내장된다고 `F08.Fab 웨이퍼 세정`이나 `B08.독립 검사장비`로 부풀려 배치하지 않음. B08 배치는 오직 **별도 6-SIDE INSPECTION** 근거.
- [DISCO 공식 제품 목록](https://www.disco.co.jp/eg/technology/) 및 [DISCO 2025 패키지 다이싱 제품 발표](https://www.disco.co.jp/): DISCO는 웨이퍼 다이싱만이 아니라 **패키지 다이싱 제품도 있음**. 기업을 배타적으로 '웨이퍼 vs 패키지'로 단정하지 말고 해당 제품별 기능 태그와 매출노출을 확인한다.

## 유사 분류 오류(기존 검증 사례)
- ISC F08 세정 케미컬, F10 EFEM: 인수 사업/제품 존재는 확인됐지만 공정별 매출비중이 확인되지 않았는데 공식 WATCHLIST에 먼저 배치한 상태였음. **B09 소켓** 주력과 F08/F10 승격 검토 큐를 구분해야 함.
- Hanmi B04/B08 역시 제품 존재와 전사 매출 중요도는 다르므로 무조건 3공정 Primary로 취급하지 않는다.
- `장비 생산 기업`과 `소재 공급사`가 동일 공정에 있더라도 설비 CAPEX 베타 vs 웨이퍼/출하량 베타가 달라 **하위 피어를 나눠야 함**.

## 우선 순서
1. 기존 309 공정배치행 각각 `제품·기능/가공 대상/역할/매출비중·confidence/출처/Primary·Secondary·Review`의 하위 태그로 재매핑. **검증되지 않은 매출 비중을 추측 사실로 만들지 않음**.
2. B03·B04·B05·B08/ISC F08·F10의 즉시 경계 오류부터 교정 대기열로 묶어 점검.
3. F03/F04/F07/F08/F10에서 장비·케미컬·챔버부품·인프라 공급자 혼합을 해소.
4. 결과를 승인된 신규 WATCHLIST 버전으로 남긴 뒤 삼성 POP 6그룹 SBT의 `@#` 소제목을 하위 STACK 기능별로 구성. 기존 SBT와 감사용 원장 원본은 덮어쓰지 않음.
5. PLAY는 이후 적합한 독립 이벤트 동인만 연결; 기존 단순 테마의 상품종류를 동인으로 오인하지 않음.
