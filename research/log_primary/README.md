# 주가위치탐색기 — 로그 5·7등분 공식 연구 인덱스 (2026-10-20)

## 2026-10-20 표본 편향 교정 — 주도주 전체 평균이 상투 터치보다 먼저

**[활성 표본선정·평균 검증 프로토콜](../methodology/LEADER_UNIVERSE_FIRST_MEANS_NOT_TOP_TOUCH_20261020.md)**: 작성자가 과거 주도주 전체를 분석했다고 기술했으므로 **원작 상투선 접촉 성공사례만으로 평균을 구하는 것 금지**. 2016~18 SK하이닉스·삼성전자는 기존 옛 SMA240 실험에 기록돼 있었는데 **38개 Adj_Close 코호트에 빠져 있음**. 옛 두 파일에서 상승배율 약 **SKH 3.81~3.91×, 삼성전자 2.64~2.71×**로 차이가 있어 아직 수정주가 통합평균에는 섞지 않음. 사후 실제 고점 `H`와 저자 자동 '상투선' `T(t)`을 같은 개념으로 취급하지 않는다. **역사 전체 주도주 모집단 선정 → 저점/고점 및 로그 5·7 단계별 평균 계산 → 이후 독립 원작 밴드 도달 결과 검증**이 순서. 종목이 허리에서 끝나도 주도주로 선행 선정됐다면 평균에 들어간다.


## 2026-10-20 — 사용자 기존 원본 5기업·7장 전수 재검토

- [**기존 실제 원본 7장 통합 공통점·반례 검산 보고서**](../results/ORIGINAL_CHARTS_FIVE_COMPANIES_SEVEN_VIEWS_REANALYSIS_20261020.md) / [**정규화 7화면 CSV**](../results/original_5_companies_7_charts_commonalities_20261020.csv). 삼성전기 1, SK하이닉스 2, 가온전선 2, SK㈜ 1, 역사 SK텔레콤 1; **총 5회사, 7캡처**. 사용자 제외 주식은 분석집합에 없음.
- **공통 구조:** 다층 위치선 순서/장기 경사가속/주가가 먼저 뛰고 밴드가 상대적으로 느리게 따라감/여러 화면에서 상투·무릎 전체폭의 *국면별 확대*. 단 이 7장은 상승구간을 선택한 회고 이미지, 초과 배율 법칙이나 선행 매매식 아님.
- **중요한 반례:** 삼성전기·SKH·SK㈜에서는 중간선이 전체폭과 함께 이동하는 `H1` 조건부 설명이 더 좋았지만, **가온전선 5월·10월은 상투대비 중간선 간격 유지 `H0`가 더 낮은 픽셀 오차**. 따라서 `q_i` 하나를 모든 종목/시점의 고정 상수로 정하지 않는다.
- **7화면의 q 범위:** 어깨 0.206~0.237, 허리 **0.378~0.438**, 허벅지 **0.704~0.723**. 허벅지가 상대적으로 안정적으로 보여도 정확 5/7이나 Fibonacci n항이라고 확정 금지.
- **품질:** 가온전선 2026-05-11 원본 가격축은 **선형**, 2026-10-14는 **로그**; 회사의 2026 무상증자까지 있어 캡처간 동일 과거일의 원화 밴드 비교/리페인팅 주장 금지. 기존 연구에서 로그등분을 기준으로 쓰는 것과 원본 가격축은 별개의 문제.
- **다음 최우선:** SKH 정확 동일 거래일 두 캡처 교차 + 별도 대상투 선 시계열 복원. 38개 완료주도주의 로그등분 평균은 사후 분포로만 보존.

## 1. 운영 수학 및 평균 통계

- 가격원장: **사후** `L=최저 Adj_Close>0`, `H=L 이후 미리 정한 시세 종료기간 안의 최고 Adj_Close`. `R_i=H_i/L_i>0`.
- 운영형 로그 5·7 가격 단계: **`G_{i,j,k}=R_i^(j/k)`, `P_{i,j,k}=L_i×G_{i,j,k}`, `k∈{5,7},j=0..k`**. 즉 로그가격을 균등 등분하므로 `P_{i,j,k}/P_{i,j-1,k}=R_i^(1/k)`. 시간 5/7등분 아님.
- 집계는 반드시 **사이클별 G 계산 → 같은 j끼리 사이클간 산술평균**, **사이클별 로그 한 구간 배율 계산 → 사이클간 산술평균**. `mean(R^(1/k))^j != mean(R^(j/k))` (일반적으로).
- **잠정 운영 38건**: 평균 R=8.560594386배, 로그 5구간 평균 **1.503831710배**, 로그 7구간 평균 **1.336894306배**, 34기업. 초과 변동 1건 *효성 2007*을 포함(FLAG=1). 기준값의 품질경고 필수.
- **검증 민감도 37건**: 평균 R=8.558080715배, 로그 5구간 **1.502861985배**, 로그 7구간 **1.336240502배**, 33기업.
- 유효 사후 가격값 38건 중 **추가 8건 잠정 복원**, 나머지 기존 30건도 `Adj_Close`로 통일. 아직 공식 거래소 조정주가 독립 재조정 및 모든 법인 기업행위 실사 **미완료**. **주가 로그축 출력**과 **로그 간격 계산**은 별개다.

## 3. 원작 역산은 별도

원작 보관 전사는 **"저점~고점 5등분·7등분 → 등분마다 기록값을 Fibonacci n번째 함수에 대입 → Elliott 국면에 따라 선 이동"**까지만 제공. 어느 값/평균을 뜻하는지, 로그인지 선형인지, `F_n` 인덱스/단계가격 원식과 무릎 이벤트 가격 등은 미공개. **임의의 피보나치 항이나 1.5038배 5회 복리를 곧 원작 상투 목표로 선언하지 말 것.**

활성 원작 차트 4종목 외 보조 연구를 새로 추가하지 않고, 기존 이미지의 로그 화면위치 `q`는 **로그가격축 출력 상대좌표**라는 별도 지표임을 유지.
