## 2. 하나의 공통된 실험식 / 성공 기준

**먼저 원작이 사용한 가격분할의 기초 L,H를 사후사이클 극점인지, 무릎 통과 당시 사용 가능한 앵커인지 분명히 한다**. L,H 후보는 분리 보관하고 사용자 승인 없이 고점을 뒤에서 변동해 원작 목표가에 맞추지 않는다.

1. **운영 기준 — 로그/동일배율 가격등분:** `T_{j,k}=L(H/L)^{j/k}`, `k=5 또는 7`, `j=0,...,k`. 기존 38개 `Adj_Close` 통합 원장과 동일한 기준 사용. 로그 차트 출력만으로 원작도 로그분할이었다고 증명되는 것은 아님.
2. **LEGACY/대조 — 선형 가격폭 등분:** `L+(H-L)j/k`는 예전 결과의 재현·반증 전용이고 신규 비교의 기본값으로 선택하지 않음.
3. **Fibonacci 고정 후보** — 기존 연구 전사가 언급한 `0.236/0.382/0.5(비정통 Fibonacci)/0.618/0.786/1/1.272/1.618/2/2.618/4.236`; 원본 텍스트에 특정 대응 n이 없으므로 **임의 n 뒷맞춤 금지**. 예시용 모델과 실제 원식 판정을 따로 기록.
4. 5/7 **계산 숫자**와 실제 원작 [무릎·허벅지·허리·어깨·상투·대상투]가 일치하는지 같은 관측 날짜, 같은 가격 수정단위에서 비교. 원작 대상투 라벨 가격 없는 화면은 **미확인**.
5. 검증 표본 4개 중 적어도 2개 독립 종목에 적용한 후 **기존 고정 비율**이 별도 자유계수 없이 재현되어야 후속검증 통과. 한 기업에서 새 계수를 최적화한 뒤 다른 기업에서 쓰는 것이라면 그 사실을 가설로 명시.
6. 오류범위/기업행위 수정/원작 캡처가 과거를 2026년에 재계산한 리페인팅 가능성 보유. **당일 알 수 없던 H를 집어넣은 사후 분할 결과는 미래 예측 성적에 절대 포함하지 않음**.
