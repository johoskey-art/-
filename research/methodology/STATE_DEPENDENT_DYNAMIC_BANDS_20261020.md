## 1. 표본·질문의 교정

- **ACTIVE 우선 순서**: **SK하이닉스** (주도/광기/시간변화) → 삼성전기 → 역사 SK텔레콤 → LS ELECTRIC (실제 5선 원작 화면 미확보). 쎄트렉아이 099320와 그 `주가위치2` 툴팁은 **ARCHIVE_NONACTIVE, 어떠한 신규 공식 학습·반증·교차검산에도 사용 금지**. 과거 파일은 연구 변경이력 추적을 위해 삭제하지 않음.
- 원문의 **과거 주도주 상승폭 5·7등분 → 단계별 숫자 기록 → 피보나치 n번째 함수 → 엘리어트 시세 국면에 따라 위치선 이동** 중, 특히 *마지막 이동 단계*를 진지하게 취급한다. 38개 사후 수정종가 로그구간 평균 `1.503831710/1.336894306`은 경험적 초기 분포일 뿐 위치선 상수/주가 한계치가 아님.
- 주도주 시대·섹터·실적/테마·시총·수급·광기 국면마다 상승폭/상단 위치선이 달라진다고 가정하고, **고정된 하나의 피보나치 항이 모든 종목/시점에 맞는지**를 핵심 연구 목표로 삼지 않는다. 변화를 인과적으로 설명할 수 있는지 평가한다.
- **탐색적 2:3, `q=1/5,3/7,5/7` 등 고정비 가설은 `LEGACY_EXPLORATORY`**로 등급 하향. 의사결정의 운영계수로 사용 금지. 기존 로그화면 q 평균 `0.218/0.417/0.716`은 관측된 **조건부 중앙 관계 및 허용 오차 범위**의 일부이지 영원히 고정될 정답이 아니다.

## 2. 정답으로 가는 두 경로 (별개)

**구조/기초 가설 (귀납):** 과거 상승완결 38개(8잠정 포함)의 5·7등분 배율 *분포*에서 레짐별 초기 범위/전형적인 단계 이동 크기를 얻는다. 고점을 미리 알고 계산한 평균이므로 당시의 미래 상투선을 맞혔다고 주장하지 않는다.

**동적/시세국면 가설 (연역·시계열):** 한 종목에 여러 시점의 자동 위치선 출력이 있다면, 공통가격 데이터가 변할 때 상투·대상투·무릎의 **절대가격·기울기·상하폭이 어떻게 변하는지**를 파악한다. 수급/광기의 대용 지표는 거래량, 거래대금, 상대강도, 변동성, 추세 지속성, 동행종목 돌파, 재상승 여부 등 **당시 시점에 알려진 변수**만 시험한다. 종목별 계수/타겟을 사후 결과에 딱 맞춰 만드는 행위 금지.

아래는 **연구를 위한 관측량 정의**이지 원작자 알고리즘을 창안/확정한 것이 아니다.

```text
time_date t = 차트 가로축 원거래일
capture_time s = 원본 차트 캡처/조회일 (t 와 다를 수 있음)

K(t;s) = 원본 '무릎' 표시 가격
T(t;s) = 원본 '상투' 표시 가격
X(t;s) = 원본 '대상투' 표시 가격 (없으면 NA)

top_knee_log_width w(t;s) = ln[T(t;s) / K(t;s)]
exuberance_premium e(t;s) = ln[X(t;s) / T(t;s)] (대상투가 관측되면)
inner_log_fraction q_b(t;s) = ln[T(t;s)/P_b(t;s)] / w(t;s)
  b = 어깨·허리·허벅지; q_b는 국면/시점에 따라 변할 수 있음.
```

**전제는 절대 레이블 분리**: `상투`를 `대상투` 또는 `울트라상투`로 혼합하지 말고, 후자의 가격을 증거 없이 상투 배율에서 만들어내지 않는다. `w`, `e`, `q`가 일정할 필요 없다.

## 4. 다음 *실제로 실행할* 검증 순서

1. **SKH 두 원본 화면을 실제 거래일 단위로 정렬:** 화면축에서 사용 가능한 주/월/일 날짜틱을 읽어 x→t 대응을 명시적으로 복원. 가능한 날짜 범위만 공통 t 비교하고 일자 불명확 시 NA. 픽셀 좌표를 임의 날짜로 채우지 말 것.
2. **상투·대상투 각각 분리 채록:** 두 이미지에 해당 자동색 선/레전드·가격축 근거가 명확할 때만 대상투 레벨 추가. 자동 밴드와 사용자가 그린 노란 선/이평선은 분리. 대상투 원화 숫자가 없어도 빨강 상투·파랑 무릎의 시계열 `w(t;s)`은 계속 분석 가능.
3. **고정 vs 움직이는 위치선 대조:** (a) 로그상하폭 일정 `w(t;s)=c` (b) 같은 종목 내부 w의 변화 (c) 국면 전환일 전후 폭 이동을 비교. **예측값이 딱 맞는지 대신 범위·방향·시점·잔차** 측정.
4. **국면·광기/수급 가설 검정:** 당시의 거래대금 증가율·동일섹터 주도주 동행성·상대강도·급등/완만 추세·변동성·재상투 여부 등을 **해당 t 이전 정보로 고정**하고 `w`/상단 변동과 연관성 비교. 표본이 적으면 근거와 반례로 제한.
5. **리페인팅 검사:** 같은 거래일 t가 캡처일 s1과 s2 화면 둘 다에 보일 경우 `T(t;s1)` vs `T(t;s2)`, `X(t;s1)` vs `X(t;s2)`, `K(t;s1)` vs `K(t;s2)` 비교. 불가능하면 `REPAINT_UNTESTED`.
6. **검증 범위 확대는 같은 주도주 우선:** SK하이닉스에서 구조/전이 조건을 정리한 뒤 삼성전기·SK텔레콤과 대조; LS ELECTRIC 원본은 찾을 때만 사용. 1개 작은 종목의 고정 등분성만으로 범용 법칙을 만들지 않는다.
