# 장기 위치선 비율·움직임 우선 검증 프로토콜 (2026-10-18)

## 제안의 출발점

사용자 가설: 원 저자가 특정 시장상황에 따라 위치선 값을 약간씩 수정할 수도 있으며, 하루짜리 무릎 통과일보다 **장기 밴드의 상대 비율·간격·기울기**가 실제 알고리즘을 구별하는 데 더 중요할 수 있다.

**상태: H(가설) / 수치 측정 미완료.** 저자가 수동으로 조정했다는 직접 자료는 없다. 자동 재계산, 국면 변화, 기업행위 수정, 차트 축 변경도 외형을 바꿀 수 있음.

### 측정 단위

날짜 t에 그려진 특정 밴드 i의 가격을 L_i(t|s)로 표기한다. s는 **그 차트를 저장·관찰한 시점**이다. 같은 과거 날짜 t라도 s가 바뀌면 이후 재계산/리페인팅으로 값이 바뀌었을 수 있으므로 s를 절대 버리지 않는다.

확인된 범례: 무릎(K, 파랑), 허벅지(T, 주황), 허리(W, 검정), 어깨(S, 초록), 상투(P, 빨강). '대상투'는 해당하는 원본 화면에서 실제로 보일 때만 포함.

| 관측량 | 수식 | 무엇을 판별하나 |
|---|---|---|
| 인접 밴드 비율 | r_i=L_(i+1)/L_i | 계층간 고정 배율인지 |
| 인접 로그 간격 | g_i=ln(r_i) | 큰 상승·분할 보정 후 상대 거리 |
| 전체 폭 | w=ln(L_상투/L_무릎) | 상하단이 함께 벌어지는지 |
| 내부 상대 위치 | q_i=ln(L_i/L_무릎)/w | 밴드 전체폭과 별개로 내부 구조가 유지되는지 |
| 장기 로그 기울기 | v_i(h)=[ln L_i(t)-ln L_i(t-h)]/h | 각 밴드 20/60/120/250거래일 이동속도 |
| 상단·하단 기울기 차 | v_상투(h)-v_무릎(h) | 팬처럼 펼쳐지는지, 평행 이동인지 |
| 동일 과거일 재계산 차이 | R_i(t;s1,s2)=ln[L_i(t|s2)/L_i(t|s1)] | 수동 조정일 가능성을 포함한 과거선 사후변경 여부 |

### 먼저 검증할 중첩 모델

- **H0 고정 비율형**: L_i(t)=B(t)×c_i. 모든 r_i와 g_i는 상수; 로그기울기 v_i도 동일하다. 기존 앱의 SMA240×상수는 H0형 대조 모델 중 하나일 뿐 원저자 원식으로 확인되지 않았다.
- **H1 가변 전체폭·고정 내부형**: ln L_i(t)=b(t)+q_i×w(t). 공통 밑선 b, 전체폭 w는 함께 변화하지만 내부 구조 q_i는 고정. 밴드가 장기적으로 펼쳐지거나 좁혀지는 **최소 복잡도 새 후보**.
- **H2 국면별 내부구조형**: ln L_i(t)=b(t)+q_i(z_t)×w(t). z_t를 **그때까지 관측된 정보**로만 정의. 상승/횡보/하락에 따라 q_i도 변화하는지 검증. 충분한 수치 없이는 과적합 우려.
- **H3 명시적 재조정형**: 과거 어느 시점에 원저자나 프로그램이 계수/앵커를 재설정할 가능성. H0~H2에서 설명 안 되는 장기 값 변동이 발견되더라도 원인이 '사람의 손'이라고 결론내릴 수는 없다.
- **대조 모델**: 가법형 L_i=A(t)+c_i S(t), 장기이평×고정계수 등. 수식별 자유도와 표본외 오차가 같아야 한다.

### 왜 장기차트가 중심인가

- **관측 주기**: 2~5년 연속 기록, 약 20거래일 간격 선가격 측정, 20/60/120/250거래일 로그 기울기 비교. 단기 캡처의 하루 커다란 양봉은 결과변수이며 알고리즘의 장기 구조 증거는 아니다.
- **첫 동일종목 서로 다른 캡처**: 000660 SK하이닉스 2026-07-28 vs 2026-08-07. 같은 과거일 t의 각 위치선이 다른 저장시점 s에 얼마로 나타났는지 비교.
- **두 번째**: 000500 가온전선 2026-05-11 vs 2026-10-14. 2026-06-30 권리락과 1주→1.8주 무상증자 영향으로 과거 가격을 동일 보정단위로 환산 후 비교. 미보정 축의 겉보기 움직임으로 리페인팅을 주장하면 안 된다.
- 기존 6개 차트는 보존된 텍스트 리뷰에서 위치선의 층위·곡률을 관찰했지만 **밴드 자체 원화 수치가 확보된 것은 아니다**. 증거: ../evidence/20261017_blog_six_chart_review.md.
- 가격이 숫자로 표시된 원작 차트나 같은 화면의 다수 기준축이 확보되면 픽셀을 가격으로 사상해 측정오차·선 굵기·축 로그 설정·x축 종목거래일을 모두 감사한다.

### 판별 기준과 주의

1. g_i가 안정되면 H0 보류/지지. g_i가 시간에 따라 의미있게 변하지만 q_i가 일정하면 H1이 간명하다. q_i도 변하면 H2를 검토한다. 모든 판정은 표시화면 숫자 오차보다 큰 경우에만 가능.
2. 동일 과거일의 밴드가 다른 화면에서 달라져도 분할·축·기간·후행 원자료 변경을 제거하지 않으면 원저자 재조정이나 리페인팅의 증거가 아니다.
3. 원작의 **저점~고점 5/7등분→종목별 평균→Fibonacci n번째 항**은 과거 완료 사이클의 학습 파트, b(t),w(t),q_i(t)는 실시간 밴드 생성 파트로 분리. 가격폭 균등분할 평균의 항등식은 별도 신호를 만들지 않는다.
4. 정확한 무릎 날짜 2개(로보티즈·이수)는 **장기 밴드 형상과 모델에서 다시 설명돼야 할 사건점**으로 보존. 이 날짜에 억지로 기울기를 맞추지 않는다.
5. **지금은 방법론 변경 단계**. 원래 위치선 가격을 확보하지 못한 상태이므로 H0/H1/H2를 계산으로 지지하거나 기각했다고 말하지 않는다.

**첫 실행 목표:** SK하이닉스 2026-07-28/08-07 동일 과거 날짜 밴드값 비교표 1개 완성 → 가온전선 축보정 비교 → 타종목 2~5년 연속 시점에서 상대간격·로그기울기 비교. 수동 보정 여부는 가장 마지막 질문으로 둔다.
