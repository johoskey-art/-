## 1. 기존 GitHub 구현의 가정 — 공식 재현으로 오인 금지
루트 `README.md`, `backtest.py`, `kiwoom_formulas.txt`의 실제 코드에서 확인:
- `K = SMA(Close,240)`을 **무릎**선으로 놓음.

- 현행 README에 적힌 '100% 상투 한계', '실측 증명' 등 강한 표현은 재현 데이터 없이 입증된 과학적 사실로 인용하지 않는다.

## 2. 기존 실측 파일의 상충 문제
- `historical_leaders_test.txt`: 과거 상투 대비 SMA240 비율이 폭넓게 분포. 예: 에코프로 4.37 / 한미반도체 2.51 / 레인보우로보틱스 2.94 / 금양 4.59 / 삼천당제약 2.58 / SPG 4.37 / 성호전자 11.17 / 로보티즈 2.28. **4.25배 상투 고정 공식과 직접 일치하지 않음.** 자료 정의, 주가 조정, 날짜를 검산해야 한다.
- `historical_bruteforce_test.txt`: SK하이닉스 2016~18 저점 25,650 / 상투 97,700, 삼성전자 저점 21,760 / 상투 57,519.
- `historical_mega_backtest.txt`: 같은 표기 사이클 SK하이닉스 저점 22,606 / 상투 88,448, 삼성전자 저점 16,966 / 상투 45,990.
- 위의 가격 차이가 **수정주가 출처, 기간, 시가/고가/종가 등의 차이**인지 확인되지 않았음. 이전 분석 결과 수치로 재사용하지 말 것.
- `backtest.py`는 고정 SMA240 배율의 매매 검증이며, 블로거 주장인 5·7등분 평균→피보나치 n번째 함수→엘리어트 기울기 변환을 구현했다고 볼 수 없다.
- 기존 자료는 삭제/수정하지 않고 `research/` 하위의 독립 실험으로 검증할 것.

## 3. 사용자 제공 증거와 한계
- 블로거가 설명한 과거 주도주 5등분·7등분, 종목 간 평균, 피보나치 n번째 함수, 엘리어트 시세국면 이동은 **전사 및 댓글 이미지**로 확보했으나 원코드/정확한 식은 확보하지 못함.
- 2023·2026 SK하이닉스, 2017·2026 삼성전자, 삼성생명 등의 차트는 서로 다른 날짜/스케일/종목을 포함. 이미지 숫자와 실제 당시 가격을 혼동하지 말 것.
- 2023년을 보여주는 SK하이닉스 차트가 2026년에 열려 있었으므로, 그 화면을 '2023년 당시에 존재했던 예측선'으로 간주하면 **미래 정보 누출** 가능성이 있다.
- 블로거 가격선의 색상·n번째 항 규칙·선의 실제 가격은 **원본 수식 없이 미확정**.
