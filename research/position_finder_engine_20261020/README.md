# 주가위치탐색기 엔진 — 원본 차트 배치 착수 (2026-10-20)

## 목적

이 폴더는 원작 위치선의 **화면상 결과**와 종목의 **주도주성 조건**을 분리해, 실제 주가위치탐색기로 연결하기 위한 작업본이다.

- 원본 이미지(42장)는 개인 로컬 보관소에만 둔다. 저작권·출처 보호를 위해 GitHub에는 이미지를 복제하지 않는다.
- GitHub에는 이미지의 판독 원장, 파생 좌표, 계산 코드, 재현 결과만 저장한다.
- 기존 (240일선 × 고정배율) 코드는 이 엔진의 입력·검증 기준에서 제외한다.

## 이번 배치의 구성

```text
42개 화면
├─ 위치선이 있는 HTS 차트           → 라인 생성기의 관측 정답
├─ EPS·PER·ROE·영업이익 자료        → 주도주성/레짐 조건
└─ 주도주가 아닌·상승 실패 후보      → 거짓 양성(무릎 유사 신호) 대조군
```

원본 이미지 하나의 수평 픽셀 여러 개는 서로 독립 표본이 아니다. 종목·캡처 시점·국면 단위로 군집 처리한다.

## 제품 엔진의 두 층

| 층 | 질문 | 원본 배치의 역할 |
|---|---|---|
| `LeaderGate` | 이 종목은 지금 위치선을 매매·리스크 판단에 쓸 만한 주도주 후보인가? | EPS/이익추정·밸류·섹터·수급과 비주도주 반례로 교정 |
| `PositionBands` | 유효 사이클이라면 무릎·허벅지·허리·어깨·상투는 어디인가? | 원작 위치선과 과거 주도주 상승사이클 분포로 추정 |

`PositionBands`가 실제 고점 (H)를 실시간 입력으로 쓰면 안 된다. (H)는 과거 학습·검증에서만 쓰는 결과 레이블이다.

## 이번 단계의 산출 순서

1. `RAW_IMAGE_INTAKE_20261020.csv`로 42장을 차트/펀더멘털/서술 자료로 연결한다.
2. 차트 화면마다 종목·관측일·가격축·보이는 밴드·주가 위치·원작 여부를 판독한다.
3. 원작 밴드 화면은 y좌표→가격 범위로 변환하고, 펀더멘털 화면은 같은 종목/시점의 `LeaderGate` 특성으로 결합한다.
4. 비주도주는 ‘제외’가 아니라 별도 대조군으로 남긴다.
5. 그 뒤에야 동적 밴드 후보를 시점 외 검증한다. 임의의 Fibonacci n 또는 고정 계수는 만들지 않는다.
