## 2026-10-20 / 수식 식별 v1 — 화면배치와 5·7 후보 분리

- 기존 원본 7화면 전체의 내부 밴드 좌표를 재검산했다. 사용자 확인에 따라 모두 로그축으로 취급한다.
  - 어깨 q 평균 **0.218847**
  - 허리 q 평균 **0.414199**
  - 허벅지 q 평균 **0.715027**
- 직접 표준 Fibonacci 위치 (0.236/0.382/0.618)는 MAE **0.049886**로, 혼합 5/7 후보 A **0.014981**, B **0.012875**보다 현저히 나빴다.
- 두 혼합 후보의 차이는 q MAE **0.002106**뿐이다. 따라서 B가 수치상 미세하게 낮아도 원작 공식으로 선택하지 않는다.
- 관측상 재현되는 식은 `B(q,t)=T(t)^(1-q)×K(t)^q`이며, 이는 로그차트 좌표→가격 변환이다. 아직 미식별인 것은 동적 `T(t)`, `K(t)`의 생성식과 원문의 Fibonacci n 함수 역할이다.
- `MIXED_5_7_A/B`를 코드와 후보 레지스트리에 구현했지만 상태는 모두 `CANDIDATE_NOT_ORIGINAL`이다.


## 2026-10-20 / 수식 식별 v2 — 동일 원본 화면의 2앵커 구조 확인

- 삼성전기 원본 1장 21개 가로 관측을 재집계했다. 상투–무릎 폭은 **78→103px(+32.05%)**로 변했지만, 내부 q의 표준편차는 어깨 **0.00937**, 허리 **0.00764**, 허벅지 **0.00417**에 그쳤다.
- 따라서 현재 자료가 직접 지지하는 최소식은 `log B=(1-q)log T+q log K`, 즉 `B=T^(1-q)K^q`다.
- 이것은 5개 선의 배치식을 두 개의 동적 앵커로 축약한 결과이며, `T(t)`, `K(t)`을 생성하는 원작 Fibonacci 함수가 밝혀졌다는 뜻은 아니다.
- 이제 분수 후보를 더 늘리는 대신, SK하이닉스·SK텔레콤에서 동일 날짜의 실제 앵커 원화값을 복원해 `log(T/K)`와 과거 5/7 통계의 연결 여부만 반증한다.
