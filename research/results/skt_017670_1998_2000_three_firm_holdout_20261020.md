### 원본 SKT 관측 상대위치

정의 `q=(y_내부선-y_상투)/(y_무릎-y_상투)`. 원작 시세 차트는 로그 가격축이므로 이는 로그가격 상대거리이며, 저점~고점 가격폭의 산술 5·7등분과 같지 않다.

| 관측 | SKT 화면 평균 q | 삼성전기 혼합 5·7 후보 | 삼성전기 자유 q |
|---|---:|---:|---:|
| 어깨 | **0.2234** | 1/5 = 0.2000 | 0.221521 |
| 허리 | **0.4185** | 3/7 = 0.4286 | 0.426384 |
| 허벅지 | **0.7166** | 5/7 = 0.7143 | 0.717816 |

### 조건부 재현 오차 (픽셀, 낮을수록 유리)

| 삼성전기에서 고정하여 SKT에 전이한 후보 | SKT 36선 RMSE |
|---|---:|
| 자유 q (0.22152 / 0.42638 / 0.71782) | **1.220px** |
| 5·7 혼합 로그 격자 (1/5 / 3/7 / 5/7) | **2.167px** |
| 단순 0.2 / 0.4 / 0.7 | **2.741px** |
| 제한된 고정 Fib 0.236 / 0.382 / 0.786 | **6.335px** |

어깨는 정확한 1/5를 쓰면 SKT에서 약 3.19px RMSE, 삼성전기 자유 q 0.22152를 쓰면 약 0.87px. 반면 허벅지는 5/7로 SKT 약 **0.52px RMSE**. **일괄적으로 정확한 5/7 분할 격자라고 단정할 수 없지만 특히 허벅지 q≈0.714 주변의 상대 위치는 독립 회사 원본에서도 재관측되었다.** 1~4px 중심판독 오차, 캔들/노란 대각선 마스킹 및 동일 제작자·버전 가능성 때문에 1px 미만 우위의 통계적 유의성은 주장하지 않는다.

전체 픽셀 폭, 상투 가격 및 무릎 가격은 **테스트 x 위치에서 이미 알려준 값**. 이 결과는 오로지 중간선의 **조건부 화면 배치**를 설명하는 모델 비교이며 다음날 목표가격 예측력이 아니다. 저자 미공개 피보나치 `n` 함수의 기각 또한 아니다.

## 2. 원본 화면의 '원화 가격 환산'을 이번에 시도한 결과

SKT 원본 JPEG의 우측/좌측 가격축에 표시된 20,000·40,000·80,000·160,000원 틱을 **시각적으로 수동 선정한 y=399 / 331.5 / 263.5 / 194.5 픽셀**로 두면, `y≈1373.058−98.320 ln(원화가격)`이라는 **화면 가격축 역변환의 임시 근사식**이 된다. 네 기준 눈금 회귀 RMSE 약 0.38px이지만, 이는 수동 눈금시드의 시스템 오차를 반영하지 않는다.

화면 x=1100 (과거 화면 내 한 지점, **정확한 거래일 미감사**)에서 상투/어깨/허리/허벅지/무릎 = y **219 / 252 / 280.5 / 329.5 / 373.5**로 측정했다. 이를 단순 역변환하면 약 **125,200원 / 89,500원 / 67,000원 / 40,700원 / 26,000원**. 모두 **2000년경 회고화면에서 추정한 가격선 수준**일 뿐, 2026년 실시간 시세도 공식 HTS 툴팁값도 향후 상투 목표가도 아니다. ±4px 판독만으로 역환산 가격 약 ±4.2%에 더해 가격축 시드·수정주가 기준·오버랩 오차가 있다. 원화값의 자릿수를 정밀 실측처럼 사용 금지.

또한 **원본 가격선 중 상투와 무릎의 절대 위치를 사전 가격정보로부터 계산하는 함수는 아직 알 수 없음**. 로그 q를 이용한 보간식 `P_중간=P_상투^(1-q)×P_무릎^q`는 상투와 무릎을 관측한 후에만 성립하는 화면 환산식이며 원저자의 생성 공식이 아니다.

## 3. 현재 '원식 복원' 판정

- **COMPATIBLE(좁은 조건부 배치)**: 삼성전기, SK하이닉스, 역사 SK텔레콤 3개의 서로 다른 회사 원작 화면에서 유사한 내부 로그 위치배치를 설명한다. 특히 허벅지 q≈0.714.
- **MIXED / CONTRADICTORY**: 고정 분수 `어깨 1/5`는 SK텔레콤에서는 회사 간 전이 자유 q보다 부정확; 5등분과 7등분이 내부 위치선 분수의 직접 정의라는 증거 없음.
- **NOT_IDENTIFIABLE(원본 피보나치 가격선 공식)**: 과거 상승사이클 각 등분에서 기록한 수치가 무엇인지, 어느 Fibonacci `n`항에 어떤 순서로 적용됐는지, 두 끝선의 시점별 절대가격/기울기/무릎 통과일을 어떻게 결정했는지 미확정.
- **ACTIVE 한정**: LS ELECTRIC·삼성전기·SK하이닉스·SK텔레콤. LS 원작 차트는 여전히 미발견, 쎄트렉아이 및 가온전선의 기존 기록은 보관만.
