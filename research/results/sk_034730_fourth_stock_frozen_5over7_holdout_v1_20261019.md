# 36차 — SK㈜(034730) 제4종목: '허벅지 로그위치 = 5/7' 동결가설 독립 실험

**연구일 2026-10-19.** 35차에서 기존 **3개 기업·5개 원작 화면**의 허벅지 상대 위치 평균이 0.71345이고, 사후적으로 `5/7=0.7142857`에 가깝다는 탐색가설을 발견했다. **이번 SK㈜의 원작 사진을 검사하기 전부터 수치 5/7을 고정**해, 새로운 회사에서 얼마나 벗어나는지 테스트했다. 관측 후 적합시킨 `0.72` 등의 수치로 원가설을 바꿔치기하지 않음.

## 1. 자료와 실험 분리

- 별도 원작 **SK㈜(034730) 2026-07-28** 화면 `1000008431.jpg` (691×1536 JPEG), 사용자 제공 개인 Library에서 직접 열어 확인. 원본 SHA256 **`6a07b23fcc31186c33561281339141b8dbc74a6c0701264c28891e26c0748511`**. 공개 GitHub에 JPEG 원본이나 그 복제 이미지는 업로드하지 않는다.
- 자동 밴드 다섯: 빨강 **상투**, 초록 **어깨**, 검정 **허리**, 얇은 주황 **허벅지**, 파랑 **무릎**. **중앙의 굵은 노란 대각선은 수동 표시**로 판별해 실측 대상에서 완전히 제외. 특히 얇은 허벅지선은 좌측 300,000원 부근에서 장기간 수평으로 진행하는 줄이다.
- 원본 x=85부터 585까지 **21개의 세로 절단 위치**에서 5색 밴드 y중심을 수동 예상좌표·RGB→HSV 색상 분류·원본 추적 오버레이를 사용해 추출. 각 점의 `red_quality/orange_quality/blue_quality` **good/medium/low/manual**을 저장. 주가봉과 파란선이 겹치는 지점은 `medium`, 특정 점은 색상 검출 실패 후 수기값으로 남김. 모든 21개 지점이 서로 독립된 종목이나 거래일 관측은 아님.
- 좌측 200k~1m **7개 가격 눈금**을 원본 이미지에서 따로 읽어 `y=a−β ln P` vs 선형 가격축 비교: **로그축 β=102.9507px/ln, RMSE1.478px**, 선형축 RMSE12.464px. 따라서 동일 사진 안에서 `q=(y_주황−y_빨강)/(y_파랑−y_빨강)`은 **로그가격 기준 상대위치의 근사치**. `β`는 **사진의 화면 축 계수**, 원저자 원식 아님.

## 2. 사전 고정한 5/7 가설의 결과

정의:
`q_thigh = ln(P_top/P_thigh) / ln(P_top/P_knee) ≈ (y_thigh−y_top)/(y_knee−y_top)`,
상투 0, 무릎 1. **가설값은 단 하나 `q=5/7=0.7142857`**로 고정.

- 전체 **MAE=1.254px, 편향=+1.077px**: 가설 5/7은 실제 주황 y중심보다 평균 약 1.1픽셀 위쪽에 위치함. 원래 화면에는 굵은 선·JPEG 혼선·원본 데이터의 사후 보정 가능성이 있어 **1픽셀 차이로 5/7의 정확성을 확정하거나 기각할 수 없다**.
- **다른 고정값과 후행 비교:** q=0.70의 RMSE **3.174px**, q=0.75 **3.692px**로 동결 5/7보다 크다. 반면 **q=0.72의 RMSE=1.502px**로 5/7보다 약간 더 작지만, **0.72는 이번 자료를 본 뒤 고른 사후 비교값이므로 별도의 원작 공식 후보로 승격하지 않음**.
- **픽셀 오차 감도:** 중간선 하나의 y오차 ±2px와 양끝선 각각 ±2px를 합하면 개별 q에 **약 ±0.03 안팎**의 최악 범위가 생길 수 있음(화면 폭≈120px, q≈0.72). 21개 x는 시간상 강하게 상관되어 이 범위를 독립표본수 21의 제곱근으로 나눌 수 없다. `0.7233`과 `0.7143`의 차이는 **이 정밀도 안**에 있다.
- **판정:** `5/7` 위치 가설과 **부합하는 근사 관측**. **정확히 5/7이라는 법칙을 확인한 것이 아님**. 원래 블로거 5/7분할/피보나치 설명은 과거의 **선형 가격축 등분**일 수도 있는데, 이 실험의 `q`는 **로그가격 간격 비율**이므로 동음이의 산식을 혼합 금지.

## 4. 보조 기하검증: H0/H1 중 SK㈜는 어느 쪽인가?

- SK㈜ 원작 **같은 화면에서** 상투~무릎 y폭 시작 **119px** → 끝 **141px**. 로그축 β=102.9507 환산 상투/무릎 근사 가격비율 **3.177→3.934배(+23.82%)**. 시작과 끝 각 선의 중심 오차 ±2px이면 폭 증가량 **+14~+30px**; ±4px이면 **+6~+38px**. 방향은 중심오차 모델 안에서 양수지만 실제 색상선 혼동의 체계오차까지 없다는 뜻은 아님.
- **화면 앞쪽 7개 x에서 학습·후반 14개 x에서 중간선 3개 총42개 위치 평가:** 상투 대비 중간선 *고정 로그간격* **H0 RMSE 5.092px**, 실제 상투~무릎 폭을 입력받은 *고정 상대위치* **H1 RMSE 3.160px**. **SK하이닉스·삼성전기처럼 H1 방향 우세**, 가온전선과는 달랐다. H1이 평가구간에 이미 관측된 빨강·파랑 y를 받기 때문에 **조건부 후행 화면 재구성**이며 `W(t)`를 사전 계산할 수 있는 모델은 여전히 미발견.
- 초록/검정 선의 차트 중첩 또는 수동 보정 영향으로 H1 잔차가 커져 **각 기업의 H0/H1 결과를 비율 배치 알고리즘 자체의 확증으로 승격하지 않는다**.

## 5. 향후 반증 설계

1. **다음 신규 원작 화면을 열기 전에** `q_thigh=5/7`을 그대로 보존한다. 다른 1~3개 서로 독립된 종목에서 **종목 평균 q와 JPEG 불확실성 범위**를 함께 계산한다. 만일 정확 원화/수정주가 밴드 가격을 획득할 수 있다면 **그쪽을 우선**한다.
2. **반증 허용 구간과 계측 품질 별도 보고:** 현재 ±2~4px 기준에서 5/7과 근처 0.72의 구별력 없음. 0.70/0.75보다 작은 잔차가 나온다고 정확한 5/7이 수학적 근거라는 것은 아님. 앞으로 계측 품질이 높아질 때만 정밀 반증 규칙을 강화.
3. **원작 재계산/수동조정 실험은 별도:** 동일 과거 거래일을 서로 다른 촬영일 화면에서 정확 일치시켜야 한다. 한 장의 후행 스크린으로 수동보정 여부 판정 금지.
4. **산식 계열 분리:** (A) 실제 `5/7`이라는 **분할가격 비율**, (B) 현 분석의 `q_thigh` **로그가격 상대 위치**, (C) Fibonacci n번째 함수에 들어가는 **계수 시퀀스**는 각기 다른 정의. 서로 숫자 모양만 유사하다고 원식 복원 성공 선언 불가.
