# 원 블로거 시작일 역공학: 과거 선행 신호 전수 탐색 v1 — '강한 돌파가 최초인가?'

날짜: 2026-10-17. 상태: **C (과거 공개 OHLCV 재집계), H (블로거 기준 선택 가설), R (후보 규칙의 유일성 반증)**. 기존 원자료/모델 코드는 수정하지 않고 결과만 추가.

## 0. 결론
**'120거래일 최고 종가와 최고 장중 고가를 동시에 돌파 + 당일 +5% 이상 + 거래량 직전20일 평균 2배 이상'은 블로거의 시작일을 반드시 최초로 식별하는 규칙이 아니다.** 009540 현대중공업 2005-01-05는 검출되지만, 000660 SK하이닉스에서는 그보다 앞선 **2023-05-25, 2023-05-26**에도 완전히 같은 조건을 충족한다. 따라서 `시작일 = 해당 패턴 최초 발생일`은 **000660에서 반증**. 수치를 1.618 또는 원작 날짜에 맞게 고치지 않는다.

## 1. 방법과 사후선택 주의
- 각 종목의 **과거 유효 거래일**만 사용해, 당일을 제외한 이전 120거래일의 최고 종가와 최고 장중 고가를 따로 계산. 당일 종가가 종가 기준을 넘고 당일 고가가 과거 장중 고가를 넘으면 동시 돌파.
- 후보 부가조건 **당일 종가 +5% 이상, 거래량(당일/직전20일 평균) >=2.00배**. **이 부가조건은 원 블로그에 명시된 것이 아니라 앞선 두 날짜 관찰 후 만든 탐색용 후보**. 종목·연도가 늘어도 임계값을 조정하거나 유일한 정답으로 선언하지 않는다.
- 조사 범위: 009540 날짜 2004-01-01~2005-01-05, SK하이닉스 2022-08-18~2023-07-27. 다만 SK 데이터는 2022-08-18부터 시작하므로 **첫 120개 세션은 120일 돌파 판정 자체가 불가능**하다. SK 보이는 신호 총수는 전체 역사적 신호 수가 아니라 `120개 선행거래일 확보 후` 판정 가능한 값만 센 것이다.
- 소스: 기존 [동일 가격 정의 교차검증](hd_skh_start_breakout_close_high_v2_20261017.md)에 기록한 GitHub 고정커밋. HD의 수정종가 `Adj_Close`와 원시 `High`는 **열 내부 각각** 비교하되 서로 직접 나누지 않는다. SK 거래량은 백만 주 둘째 자리까지 반올림되어 ratio는 근사값.
- 세부 재현: [전체 14건 원장](blog_start_preceding_120day_simultaneous_signals_v1.csv) · [재현 스크립트](../scripts/blog_start_prior_signal_scan_v1.py). 원본은 GitHub 연결에서 JS로 직접 재집계하고 CSV 저장. Python 소스는 저장했으나 이 세션에서 재실행 확인하지 않았음.

## 3. 두 종목 공통되는 '선행 상승 → 조정 → 재돌파' 맥락
기존 시작일 전에 각 종목이 이미 높은 종가를 만들었다가 하락한 뒤 다시 돌파한 사실은 별도 확인됨.

| 이벤트 | 이전 상승 기준일 종가 | 이후 저점(종가) | 이전 기준일 대비 조정 | 블로그 시작일 |
|---|---:|---:|---:|---|
| 009540 현대중공업 | 2004-10-19: 17,311(수정종가) | 2004-11-18: 14,265 | **-17.60%** | 2005-01-05 |
| 000660 SK하이닉스 | 2023-06-13: 119,500 | 2023-07-10: 110,300 | **-7.70%** | 2023-07-27 |

- HD는 10/19 이후 12/29, 12/30에 이미 120일 최고 **종가**를 경신했다. 1/5는 단순 첫 종가 재돌파일도 아님. 12/29에는 120일 최고 원시 장중 고가를 돌파하지 못했고, 1/5에는 동시 돌파 발생.
- SK도 6/13에 최고 종가 119,500·고가 120,100을 만든 후 7/10에 장중 저가 109,700까지 후퇴. 7/27 재돌파. 하지만 5/25·5/26 같은 '강한 돌파'가 이전 파동에서 이미 존재.
- 따라서 **'언제 조정이 충분히 끝나 새 사이클이 시작됐다고 보았나'**는 원 저자가 별도로 채택한 추세/파동, 주가위치선(무릎) 재돌파, 또는 임의 화면 라벨 기준일의 문제일 수 있다. **그 어느 것도 현재 확인되지 않았으므로 새 코딩 규칙으로 만들지 않는다.**

## 4. 남아 있는 데이터 감사 및 새 확인
1. **000660 252일 직접 실측 미완료:** 7/27 직전 데이터가 233실거래일만 있으므로 새 자료의 250·252일 최고 종가/고가는 여전히 NA. 2022년 7월·8월 초 19일의 실제 OHLCV가 필요하다. 과거 52주 신고가를 명시한 2023-07-27 동시대 언론 기사와 분리. 독립 월말 가격 자료([Digrin](https://www.digrin.com/stocks/detail/000660.KS/price))에서는 2022년 7월 97,900, 8월 95,200원 수준을 제시하지만 이는 그 달 중 **모든 일봉 최고가가 낮았다는 증거가 아니다**. 월말 숫자로 252일 극값을 채우지 않는다.
2. **009540 2017년 기업분할:** 2017-04-01 분할기일 및 2017-05-10 재상장/신규상장 사실은 [2017 KRX 공시 자료](https://kind.krx.co.kr/external/2017/09/26/000031/20170926000052/10601.htm)에서 확인. 외부 가격사이트도 [2017-05-10과 2018-01-31 조정 사건](https://kr.investing.com/equities/hyundai-heavy-industries-historical-data-splits)을 표시하지만 이를 `009540.csv`의 2005년 `Adj_Close`에 그대로 환산하는 계산은 **불가**. 실제 역사 조정계수·현존/분할신설 법인 대응을 KRX 원시파일과 독립 대조할 것.
3. 원본 009540 2005-01-05 행은 `Open=22,160, High=23,814, Low=22,160, Close=0, Adj_Close=18,665`. `Adj_Close`가 원시 저가보다도 낮으므로 **원시 장중 고가와 수정종가를 하나의 시세 스케일로 읽을 수 없다.** 이번에는 각 열 기준 120일 신호만 비교했으며, 서로의 절대 가격비는 계산 금지.
4. 블로거 원문 별도 단서: GitHub 보존 `blog_224280566920.txt`에는 **로보티즈가 2025-05-14 '무릎을 통과'**했다는 명시적 설명이 있다. 그러나 이는 블로거가 **'한 사이클의 시작일'**이라고 적은 사례와 다른 *무릎 통과 사건*이다. 차기 독립 비교 후보로 등록하되 두 종류를 섞지 않는다.
