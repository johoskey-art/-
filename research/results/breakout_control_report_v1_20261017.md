# 연구 v1.2 — 52주 신고가 돌파의 실패 사례 대조군
작성일 2026-10-17 · 상태: **일별 종가 기반 실측** / 정확한 블로거 위치선 모델 검증 아님

## 0. 목적
이미 크게 오른 성공 주도주에서만 저점~최고점을 골라 5등분·7등분하는 것은 생존/사후선택 편향을 일으킨다. 주가 위치선의 예측 유용성을 검증하기 전에, **사전에 정의할 수 있는 객관적 출발 이벤트**를 만들고 이후 결과의 분모를 확보한다.

## 1. 신호 정의 (당일 정보까지만 사용)
1. 252거래일 이전 종가의 최고값 `H_252=max(Close[t-252:t-1])`을 계산.
2. 당일 종가 `Close[t] > H_252`면 52주 신고가 돌파 이벤트로 기록. 120거래일의 **중복 신호 방지 기간**을 적용. 단, 이전 신호로부터 120일 이후에는 같은 기업에서 다시 신호를 기록할 수 있음.
3. 이벤트 날짜로부터 **향후 120거래일 종가** 및 그 사이 최고/최저 종가를 측정. 신호 날짜부터 120일 앞의 가격은 **라벨**에만 사용, 신호 선택에 사용하지 않음.
4. 기업행위 오염 방지를 위해 주변 252일 과거~120일 미래 구간 중 연속 종가가 하루에 0.5배 미만/1.5배 초과로 변화한 경우 그 관측 제외. 실제 초급등/폭락도 제외할 수 있으므로 데이터 품질 필터의 비용 기록.
5. 개인 매매 가능 가격이나 수수료를 가정하지 않는다. 이것은 가격 후행 결과 관측이지 거래전략의 체결/손익 백테스트가 아니다.

**스캔 범위** (기존 실험용 10개 기업의 시세 가능한 일부 기간):
현대차 2006~2017 / 기아 2006~2017 / LG화학 2006~2017 / POSCO 2001~2013 / 삼성중공업 2001~2013 / 삼성전자 2008~2017(액면분할 전) / SK하이닉스 2010~2021.04 / 한미약품 2011~2021.04 / Tesla 2015~2025 / NVIDIA 2010~2025.

## 3. 해석과 한계
- 주도주로 알려진 기업도 신고가 돌파가 항상 성공하지 않음. 120일 후 실제 종가가 오히려 하락했던 신호 24건이 있음.
- **이 결과로 과거 평균 곡선 또는 피보나치의 유효성을 검증한 것은 아니다.** 이번 신호는 실제 블로거의 '무릎/허벅지 위치선'과 같은 신호가 아니기 때문.
- 선정된 기업 10개 자체가 역사적 유명 성공기업임 → **기업 단계 생존 편향 유지**. 비주도주·퇴출기업·유사 섹터의 후보 기업까지 포함해야 진짜 대조군.
- 스캔 기간·120일 대기·+40% 성공 기준 등은 **연구용 선택**이다. 유사 기준을 여러 개 시험할 때는 사전등록하고 다중시험/결과 선택을 피한다.
- 120일 최고값은 사후로만 알 수 있는 값. +40% 접촉이 가능했더라도 그때 팔 수 있었는지·최종 손익이 +40%인지는 증명되지 않음.
- 소스마다 주가 보정/계산법 차이가 있으므로 정밀 실매매 검증 전 별도 공식 시세 감사 필요.

## 5. 후속 순서
1. **이전 사이클 고점 정의 개선:** 2년 최고가 대신 스윙 저점/고점 및 이전 박스 돌파점의 객관적 알고리즘 후보 구현.
2. **비주도주/실패 기업 모집:** 동일 시기·섹터에서 252일 신고가 돌파하였으나 5~7배 이상 상승하지 못한 종목 및 퇴출 종목 추가.
3. **실시간 위치선 비교:** t일 이전 데이터만으로 발목/무릎/상투 추정밴드 산출 → 신고가 돌파 대조군 93개 이벤트의 미래 성과 대비 성능 증가를 확인.
4. **외부 출처 시세·기업행위 검증:** 가장 중요한 데이터 오염/수정주가 불일치부터 해결.
5. 실적형 vs 테마형 유의미한 차이와 파동 기울기는 충분한 독립 데이터 확보 후 테스트.

**원칙:** 성공 사례의 기울기만 예쁘게 재현하는 모델을 성능 있는 미래 위치 탐색기로 간주하지 않는다.
