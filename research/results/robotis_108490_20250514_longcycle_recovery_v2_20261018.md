- 기록일: **2026-10-18**
- 상태: **O (원 저자의 날짜/외부 기록), C (관측된 두 수치 간 단순 계산), H (장기 전고점 회복이 무릎선의 원리라는 가설), NA (직접 252거래일 OHLCV 미확보)**.
- 목표: 블로거 '무릎 통과일'이 단순 상한가가 아니라 **이전 장기 사이클 고점의 재돌파일**인지 검증. 원본 지표 함수 발견이라고 주장하지 않음.

## 1. 새 핵심 단서 — '이전 장기 고점 회복' 날짜 일치

서로 다른 소스 [주가맵 역사/회복기간](https://jugamap.keywordegg.com/stock/108490/history)은 로보티즈의 **2023-03-30 고점 → 2024-08-05 저점 약 -63.1%** 하락구간을 판별한 후, **2025-05-14이 직전 고점의 종가 기준 회복일**이라고 표기한다. 해당 서비스는 **네이버 일봉·월봉의 추후 수정주가**라고 명시.

이 날짜는 원 저자가 [기존 전사](../../blog_224280566920.txt)에서 **2025-05-14 '무릎 통과'**라고 부른 날과 같다. '한 사이클 시작일'(009540·000660)과 '무릎 통과일'(108490)이 본질적으로 같은 사건인지는 여전히 확인되지 않았다.

**해석 (H):** 원 저자가 무릎 통과일을 **장기 전고점 회복 + 새로운 주도주 국면 인정**과 연결했을 가능성. 다만 하나의 회고 날짜만으로 무릎선 계산식이나 원인성을 증명할 수 없다.

## 2. 별도 52주 고점 자료의 직접 수치

공개 GitHub [dalinaum/rs 원장 2025-05-13](https://github.com/dalinaum/rs/blob/19dabf3f129faee0518152a43c1db09be49b5434/docs/_posts/2025-05-13-kosdaq-trend-template.markdown), [2025-05-14](https://github.com/dalinaum/rs/blob/19dabf3f129faee0518152a43c1db09be49b5434/docs/_posts/2025-05-14-kosdaq-trend-template.markdown)는 미너비니 트렌드 템플릿 표에서 로보티즈를 다음처럼 표시한다:

- 05-14 당일 **49,000원은 05-13 표의 기존 52주 최고가 42,350원보다 15.70% 높다** (같은 자료 계열의 원 표시가 비교, 계산 C).
- [별도 상한가 원장](https://puzizig.com/programs/stock_upper_limit/code/108490/)에는 05-14 시가 39,900·고가 49,000·저가 38,550·종가 49,000원, 거래량 3,389,475주, 전일 대비 +29.97%로 제시됨. 종가 37,700 → 49,000은 **+29.97%**.
- **하지만 52주 가격 극값 표기와 당일 뉴스는 직전 정확한 252개 실거래일 최고 종가/고가를 같은 알고리즘으로 직접 집계한 자료와 다르다.** 20/60/120/240/250/252 극값 **정확한 수치**, 거래량 직전20일 평균 **정확한 비율**, 그리고 모든 선행 사건의 날짜는 이번 단계에서 NA를 유지한다.
- **시간정보 오염 경고:** dalinaum 표의 YAML 작성시각은 **2025-05-14 오전 07:25**인데 표에는 그날 *마감 후에야 확정되는 종가 49,000원*이 포함된다. 따라서 이 파일을 **그 시각에 실제로 존재했던 신호/거래정보**로 취급하면 명백한 look-ahead 오류. 이 파일은 **사후 이력의 가격 교차검사 자료**로만 사용하고, 원 저자 지표의 실시간 선행 시그널 증거로 사용하지 않는다.
- 추가 [StockNote 후행 백테스트](https://stocknote.ai.kr/quant/result/2766/)의 2025-05-14 종가는 **47,717원**으로 원시 종가 49,000원과 서로 다른 조정 스케일이다. 양 가격을 혼용한 5·7분할/252일 수치를 **생성하지 않는다**.

## 4. 필요한 완전 일봉과 재현성 계획

**미달성:** 여러 접근 경로를 조사했으나 이번 실행환경의 네이버 `fchart.stock.naver.com` 역사 일봉 요청·Yahoo 차트 호출이 막혀 **2025-05-14 이전 252개 이상 동일 가격 단위의 완전 OHLCV를 내려받지 못했다**. 공개된 월말 데이터는 일봉 최고가를 재현하지 못하므로 대체하지 않았으며, 공개 GitHub의 `choosunsick/Korea_Stocks_Full/108490.csv`는 **2021년까지**, `dooboostore` 108490.KS 일봉 캐시는 **2025-07부터**여서 목표시점이 없다.

- 새 [네이버 XML 전체 일봉 수집·검산 스크립트](../scripts/robotis_naver_historical_replay_v2.py): `requestType=1`로 **2022-01부터 2025-05-15까지만** 조회, `Volume>0`, OHLC 단위 일관성 검사, 대상일 직전 20/60/120/240/250/252실거래일 극값/돌파, 120일 동시돌파의 *그보다 먼저 발생한 날짜* 전체 계산.
- 재현성: 저장된 원문 XML, 원본 SHA256, 조회시각, 원본 OHLCV CSV, 사건별 결과 JSON, 선행 신호 CSV를 출력. 추후 수집 후 **원문 XML을 그대로 기록하고 커밋**해야 데이터 수정/리페인팅을 재검사 가능.
- 이번 환경에서는 실제 네이버 원문 응답이 없어 **스크립트의 결과물을 만들어본 것이라고 주장하지 않는다**. 외부 네트워크 실행 권한을 가진 PC/Work 환경에서 실행 후 같은 원장에 결과를 붙일 것.
- 이번에 확인한 교차 자료 6행은 [출처별 날짜·52주 고점·이평선 검산 CSV](robotis_108490_20250514_cross_source_check_v2.csv)로 보존.
- 기존 `app.py` / `backtest.py` / Pine Script 및 한국 30개 사이클 정규화 평균값 **변경 금지 유지**.

## 5. 다음 반증 지점

1. 로보티즈 **동일 기업의 다른 연도**에 52주·과거 사이클 전고점 재돌파가 있었지만 원 저자가 '무릎 통과'라고 부르지 않은 사례가 있는지 (거짓 양성).
2. 블로거가 **무릎 통과일을 다른 기업에 명확히 지정**한 사례에서 해당 날짜의 이전 사이클 장기 고점 회복 여부.
3. 단순 52주 신고가 vs 수급 급등 vs *이전 완결 사이클 고점*이라는 서로 다른 가격 사건을 30개 사후 완료 사이클에 전이하기 전 **독립 기준**을 확보.
