# 원작 '무릎 통과' 날짜 제3표본 탐색: 소스 완전성·라벨 혼동 방지 감사 v1

작성일 2026-10-18. 독립성: 이번 단계는 **원작 증거 발굴(문서 검토)**이고 **OHLCV 신규 추출·매매 백테스트가 아니다**.

## 0. 중요한 결과
- 현재 접근·보존된 원작 텍스트 **4개**를 전수 재확인했다. **월·일까지 명시된 '무릎 통과' 기록은 로보티즈 108490 2025-05-14 단 1건**.
- **연도까지만 명시된 무릎 통과 기록은 SK하이닉스 000660 2023년 단 1건**. 어느 날인지는 원문에 없다. 이를 **2023-07-27로 임의 세분화하면 원작의 차트 '사이클 시작일'과 '무릎선 통과일'을 혼합하는 라벨 누출**이다.
- 두 개의 정확한 차트 기간 시작점: 현대중공업 009540 2005-01-05, SK하이닉스 000660 2023-07-27 (기존 공유 차트 판독). 이는 **'무릎 통과'가 명시된 날짜가 아니다**.
- 또다른 **시세 본격화 설명**: SK하이닉스 2025년 **9월**, 정확한 일자 없음. 로보티즈 **2025-11-03 상투** 및 에코프로 **2023-04-10 첫 상투, 07-26 재상투**는 다른 사건.
- 따라서 **정확한 무릎날짜 코호트 n=1**, 연도 한정 무릎 사례 n=1, 차트-사이클 정확 시작 n=2. **n=3~4개의 무릎 정확 날짜가 확보됐다는 주장은 허위**가 되므로 하지 않는다.

## 2. 외부 원문 추가 탐색 결과
- 보존 텍스트 네 개에 포함된 원저자 `deekelly` 블로그 **고유 포스트 ID 10개**: `224280331610`, `224263516851`, `224260927228`, `224318120698`, `224280566920`, `224301293938`, `224278761244`, `224301269973`, `224305187498`, `224301457237`. 단 이 숫자 자체는 **후보 원문 링크**이지 읽은 본문 증거가 아님.
- 일반 웹 검색에서 `deekelly`/무릎 통과/개별 포스트 ID + 핵심 문구를 조합했지만 이번 탐색에서는 **새로운 원저자 발언·정확 날짜를 확인하지 못함**. Naver 원문 일부 주소는 검색 제공자의 robots 차단으로 본문 검사 불가. **검색 결과 없음은 해당 게시물에 정보가 없다는 증명도 아니다**.
- GitHub 사용자 저장소의 보존 전사와 6개 차트 리뷰는 읽었지만, 위 10개 게시글 중 **본문이 보존되지 않은 나머지 글을 읽었다고 표시하지 않는다**.

## 4. 기존 후보 가설의 사후 논리 체커
1. `무릎=이전 대형 상승/하락 사이클 절대 종가 고점 회복`: 로보티즈의 2025-05-14에서는 날짜 일치. 하지만 SK하이닉스는 **무릎을 2023년에 통과**했다고 저자가 회고했고, 2021년 확인 고가/종가를 2023년 어떤 날도 회복 못했으므로 **필요조건 기각(R)**. 이 반증은 정확한 2023 무릎 날짜를 몰라도 성립.
2. `한 사이클 시작=첫 120일 종가+장중 고가 동시 돌파 + 전일비5% + 거래량2배`: 2023년 000660에서 5/25·5/26 앞선 양성 신호가 확인 → **최초 규칙 기각(R)**. 이 5%/2배 기준은 원작의 원식이 아니라 사후 탐색용이므로 어떤 식으로든 최적화하지 않는다.
3. `무릎=MA240`: 기존 루트 소프트웨어의 **가설적 구현**이고 원작자의 식은 확보되지 않았다. MA240 통과일을 역산해 블로거의 무릎날짜로 새로 등록하는 것은 **순환논증**.
4. `무릎 통과가 성공주 강한 상승 직전 신호`: 원저자 **실시간(2025-05-14 이전 발행) 무릎선 예측 스냅샷** 없이 성능을 평가하면 회고적 후행 정보 누출이 발생. 현재 해당 스냅샷 부재.

## 5. 즉시 다음 실험 우선순위
- **A:** 신규 원작 명시 `무릎 통과 20XX-XX-XX` 사례 확보 → 현재 n=1 확장. 다른 게시글 제목/스크랩/보존 글을 **증거 자체가 확인되는 경우에만** 등록.
- **B:** 로보티즈 2025-05-14 이전 252실거래일 OHLCV 정확 확보 → 20·60·120·252일 극값·20일 거래량 비율·선행 거짓 신호 전수. 현재 [재현 스크립트](../scripts/robotis_naver_historical_replay_v2.py)는 저장했지만 해당 원시 장기 일봉의 네이버 응답 확보를 못한 상태.
- **C:** 2025년 5월 이전/당일 시점의 블로거 위치선 가격 혹은 공개된 과거 시점 스냅샷 확보 → **리페인팅 vs 실제 미래예측 기능** 테스트. 스냅샷 출처와 게시시각을 반드시 검증.
- **제한:** 숫자 맞추기용 1.618, 임의 피보나치 배율, 추가 EMA/추세 함수 구현은 이번 증거 발굴 단계에서 하지 않음. 국내 30개 기존 코호트, `app.py`, `backtest.py`, Pine Script 미변경.

**현재 가장 중요한 병목:** 계산 코드가 아니라 **원저자의 이벤트 정의와 그 당시 실제로 볼 수 있었던 지표값**의 독립 자료 부족. 확정되지 않은 날짜를 학습 라벨로 기입하는 오류를 막는다.
