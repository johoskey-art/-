# 주가위치 탐색기 — 연구 인계 원장
기준일: 2026-10-17 / 상태: **가설 정리·원자료 감사 단계**

> 다음 담당자는 이 문서 → `PROTOCOL.md` → `DATA_AUDIT.md` 순서로 읽고, **과거 주도주 5등분·7등분 실측**부터 수행할 것. 기존 앱의 고정 배율은 '검증된 공식'이 아니라 이전 실험의 가정으로 취급한다.

## 1. 연구 목표
- 과거 주도주의 **저점~고점 가격/시간 경로를 5등분·7등분**하고 종목 간 비교 가능한 상대값으로 정규화한다.
- 구간별 통계(평균·중앙값·분포)가 피보나치 수열의 n번째 항, 황금비 거듭제곱, 표준 확장 비율과 관련되는지 검산한다.
- **현재 종목에 적용하는 기준점**(이전 사이클 고점 / 과거 고점의 피보나치 되돌림 수준 / 현재 사이클 저점 / 돌파점)을 교차 비교한다.
- 마지막으로 **엘리어트 시세국면이 위치선의 기울기를 변형한다**는 설명을 시험한다.
- 궁극적으로 발목·무릎·허벅지·허리·어깨·상투·대상투 밴드를 원시 시계열로 산출하고, **당시 이미 알려진 데이터만 사용**하는 예측 검증을 진행한다.

## 2. 블로거의 언급 — 원문과 가설 분리

### 사용자 제시 댓글·차트에서 확인한 것
- 과거 주도주의 **저점과 고점을 연결하고 5등분과 7등분을 따로** 수행해 각 구간 값과 그 평균을 계산한다고 설명.
- 다른 종목과도 재평균하여 **피보나치 함수식**에 대입한다는 설명. 또 다른 설명에는 **‘n번째 함수’**가 언급됨.
- 엘리어트 파동이론(시세국면)을 통해 **주가 위치선들이 이동하도록 코딩**했다는 설명.
- 실적 주도주와 테마 주도주는 **상승 기간·경로가 다르다**는 설명.
- 화면에는 다층 위치선, 상단선 간격 변화, 우상향 곡선 및 완만한 하향 평행선 사례가 있음. 과거 차트가 현재 시점에 재계산된 것인지 확인되지 않음.

### 검증 전 가설
- **H1 (시간 분할):** 상승기간을 5/7구간으로 나누고 각 시점의 가격 변화를 평균.
- **H2 (가격 분할):** 가격 상승폭을 5/7단계로 나누고 각 목표에 이르는 시점·가속도를 평균.
- **H3 (기준점):** 이전 사이클 고점 또는 그 고점에 피보나치 비율을 적용한 가격을 현재 주도주의 초기 위치선 축으로 활용.
- **H4 (피보나치):** F_n, phi^n 또는 확장비율과 경험적 평균을 결합한 계수 계열.
- **H5 (국면 전환):** 시세국면에 따라 밴드 간격·기울기가 달라지는 모형. 엘리어트 기반 설명은 일반 추세·변동성 모델과 성능 비교.
- **H6 (리페인팅):** 당시 보였던 과거 선이 나중에 다시 계산될 가능성.

**어떤 가설도 현재 블로거 원식으로 확정되지 않음.**

## 3. 기본 연구순서
1. 데이터베이스: 한규범 PDF 11쪽의 주도주 후보 **국내 60개·미국 140개**에서 티커·해당 사이클을 수집하고 액면분할·합병 등 기업행위를 보정한 일별 OHLCV 확보.
2. **파일럿 10개**에서 기간 5/7등분과 가격 5/7등분을 모두 수행. 선형 가격·로그 가격 모두 계산.
3. 절대 원화 가격 평균 금지. 상승폭을 0~1로 정규화하거나 배율/로그수익률/이전 고점 대비 배율로 집계.
4. 구간별 평균뿐 아니라 중앙값·분산·이상치·구간 최초 도달일까지 기록.
5. 고정 수열·황금비·표준 확장비율과 비교하되 **사후 우연 일치** 및 자유도 차이를 엄격히 관리.
6. 이전 고점·피보나치 변형 고점·현재 저점·돌파점 후보를 각각 동일 데이터로 비교.
7. 국면에 따라 움직이는 위치선의 실시간 구현 및 독립적인 미래 기간 검증. 돌파 실패·비주도주 표본 포함.

## 6. 인계 규칙
- 증거 등급 **O(원문·원자료 관측), C(코드로 재현한 계산), H(미검증 가설), R(반증)** 을 적용.
- 실험 기록: 날짜 / 종목·사이클 / 데이터 출처·조정 기준 / 파라미터·수식 / 당시에 알 수 있던 정보 / 계산값 / 오차 / 반증 / 후속 조치.
- 미래 실제 고점으로 만든 차트는 **사후 설명 자료**이지 사전 예측력 증거가 아님.
- 과거 선이 변경되었는지 확인할 때는 **저장 시점이 다른 과거 원본**이 필요하다.
- 기존 실험 코드를 덮어쓰지 말고 `research/` 하위에서 별도 구현·검증한다.
