# A/B/C 산업 관심종목 지도 — 출력 형식 회귀 계약 v1.0

이 문서는 사용자와 처음 합의한 관심종목 지도 모양을 보전한다. HOME/EVENT/NEW/QA는 내부 분류 언어이며, 제목만 바꾼 뉴스 스크랩은 최종 결과물이 아니다.

## A. 산업지도/가치사슬과 초등학생식 설명

- 산업 주력 고객/최종 세트에서 실제 부품·공정·소재·장비까지 **화살표**로 연결. 기판의 예: 원사/유리직물·수지·동박→CCL/Prepreg→PCB(MLB·HDI 등) 또는 패키지기판(FC-BGA, 메모리용)→서버/네트워크·칩 패키지. 공정·소재·제품·용도 구분: ABF는 빌드업 절연소재, FC-BGA는 패키지기판, MLB는 다층 PCB, HDI는 고밀도 설계/가공 특성, mSAP는 공법. 동일 제품은 여러 축에 중첩될 수 있음.
- 제품마다 `간단한 비유 → 실제 구매자 → 제품이 담당하는 기능 → 매출 발생 조건`을 한눈에 보이게 함. 예: 'CCL은 회로를 새길 판재, PCB 공장은 판재를 회로판으로 가공해 고객에게 판다'. 전문 용어와 쉬운 문장을 모두 제시.
- A의 분야 분류는 서로 다른 공급·가격·고객 동인을 가진 **실제 투자상 비교 그룹**. 섹터명을 너무 뭉뚱그려 MLCC와 ABF 기판을 동일한 피어로 부르지 않음.

## B. 글로벌 피어/기업별 제품·매출 비교 — 가장 많은 분석 밀도를 배분

각 제품 그룹에서 국내/해외 동종기업을 물리적 제조/판매/계약 역할로 배치. 핵심 기업마다 다음 정보를 우선 제공:

1. **기업명·국가·실제 제품 역할** (제조/유통/장비/소모품); 핵심 고객·전방 시장은 공식/분석 추정 구분.
2. **매출 분해:** 제품·사업별 매출 비중과 절대 금액, 기준 기간, 연결/별도·분모를 가능한 한 구체적으로. 수치가 없으면 공시 제품 설명, 산업 자료의 추정, `미공시`를 혼합하지 않고 병렬 표기.
3. **가까운 피어 간 차이:** ABF 비중 유사하지만 BT/HDI나 공급 고객이 달라 제품 가격·CAPA·실적 민감도가 다르다, 변압기도 배전/765kV/특수/발주지역이 다르다는 식으로 **왜 같이/따로 움직일 수 있는지** 설명. 단순 회사 소개 복사 금지.
4. **증익 수식:** 제품별 예상 `Q × ASP × 영업마진`, 가동률·비용·환율·증설 상각비로 이익 차이를 설명하며 공개되지 않은 이익률은 추정값으로 둠. 현재 vs 미래 신규 사업 구분.

**예시 형식 (수치 반드시 실제 확인 후 삽입):**

`B2. ABF/BT 패키지 기판 — 회사 | ABF 매출/비중 | BT 비중 | 다른 핵심사업 | 가동률·CAPEX | 가격전가·수익 차이 | 출처·기준일`

해외/국내를 따로 떼는 것이 아니라 같은 제품·고객 동인끼리 모으고 해외 종목도 시가총액·거래 가능 여부와 무관하게 산업 피어로 보여줄 수 있음.

## C. 테마/EVENT → 기업·실적 모멘텀 전이

- `테마를 발견한 산업/테마 리포트·심층기사 제목/날짜` → 기술·고객의 선택 → 물량·가격·사양·공정/CAPA 변화 → 회사별 직접/간접/경쟁·피해 연결.
- 기업별 신규 이익은 **기존 매출 구성에 대비한** Q/P/Mix/원가/수율/가동률 변화로 평가. 테마가 새로워도 관련 사업이 총매출 1% 미만이거나 미양산이면 당장 EPS 수혜를 확정하지 않음.
- 긍정/부정 경로, 실제 고객 승인·반복발주·수주 잔고·이익률 등 다음 지표. 사건 새로움 vs 조사 중 처음 발견을 구분.

## D. 관심종목 등록용 리스트 (사용자가 요청할 때만)

A/B/C 결과를 기반으로 글로벌 동행 피어와 국내 회사의 실제 제품 역할을 HTS 관심종목 그룹으로 정리. 기업이 여러 산업을 담당하면 복수 배치. 포맷 import는 실측 검증된 브로커 양식으로만 출력.

## 응답 품질 검산

- **A/B/C 순서로 실제 콘텐츠가 보이는가?** 기술만 쓰고 회사/매출 비교 생략하면 실패.
- **한 산업 단위 최소한 고유한 수익 동인이 다른 세부 그룹을 분리했는가?** 범위가 너무 크면 우선 2~4개 영역을 *깊게*, 미탐색 영역 별도 표시. 고정 그룹 수를 맞추려 임의 생성 금지.
- **동종기업 간 제품 MIX·고객·실적 메커니즘 차이가 직접 비교돼 있는가?** 미공시는 미공시 처리.
- **현지어 자료·섹터별 정보 생산자를 독립 발굴했는가?** 사용자 제공 작성자 이름만 검색한 경우 미충족.
- **회사×제품/매출 숫자를 일차 공시/IR로 확인했는가?** 브로커 인용은 발견 단서, 사실 인증 아님.
- **기술 축이 섞였는가?** 예: 'FC-BGA 안에 MLB' 식의 물리적 오류를 설명 없이 확정하면 실패.
- 긴 출처 목록·테마 요약·테스트 로그로 B의 매출/기업 비교를 대체하면 실패.
