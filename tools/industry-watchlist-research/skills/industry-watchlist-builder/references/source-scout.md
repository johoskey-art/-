# SOURCE SCOUT — 산업별 자료·애널리스트·현지 연구 자동 발굴 (v1.0)

## 목표

사용자가 특정 이름/채널을 알려주지 않아도 어느 산업이나 **정보 생산자를 찾고, 그 생산자가 다루는 제품·현지 공급사로 확장**한다. 출처 이름을 고정하는 방식이 아니라 유효 검색어·저자·채널·현지 기관이 발견되며 진화하는 **source frontier**를 구축한다. 유료벽·사이트 접근 한계는 실제로 접근한 범위로 표시한다.

## 우선 탐색 자산: 사용자 기존 텔레그램 수집기

먼저 `existing-telegram-drive.md`에서 비공개 Oracle→Google Drive 수집 자료를 확인하고 실제 수집된 메시지·원문 PDF에서 산업 역할별 소스 후보를 만든다. 이 후에 공개 웹으로 아직 잡히지 않은 산업·국가·저자 및 공식 기업자료를 보완한다. Drive 수집 원본이 있더라도 같은 원본 리포트를 전달한 5개 채널은 독립 출처 하나로 센다. 공개 `t.me` 검색은 수집 범위를 보완하며, 사용자에게 양승수 등 이름 지정을 요청하지 않는다.

## 라우팅 / 검색 네트워크

1. **산업·역할 정의**: 최종 고객/장비·제품/소재/공정 역할 5~12개 임시 노드로 분해하고, 실제 핵심 생산 국가·언어를 파악한다. 종목 이름을 알고 시작할 필요 없다.
2. **한국 연구자/텔레그램 탐색**: `산업명 + 기술/부품 + 증권사/애널리스트/인뎁스`, `site:t.me/s/ + 제품명/현지국명`, `산업 보고서 + 작성자 + 현지기업/매출비중`으로 각 역할별 심층 취재/리포트/원문 연결이 많은 채널을 찾는다. 발견한 채널에서 제품 명칭·기업명·원출처·대체 가설을 추출. `message URL, 본문 일자, 원 저자/기관, 자료 유형, 원 PDF 접근 여부`를 기록. 공시·IR 인용 여부는 검증 우선순위의 단서이지 사실 보증 아님.
3. **현지 공급망 탐색**: `생산국/언어`×`제품/공정/용도`×`기업 조사/IR/월매출/협회` 조합. 한국어·영어와 실제 공급국의 현지어를 함께 쓴다. 대만: `印刷電路板/IC載板/ABF/BT/銅箔基板/背鑽/鑽針/法說會/營收`, 대만 전력: `重電/變壓器/開關設備/法說會`; 일본·독일·중국·북미 등은 산업에 맞는 용어를 해당 결과에서 확보한다. 이 예시는 씨앗일 뿐 모든 섹터의 고정 검색어가 아님.
4. **진화하는 검색어**: 보고서/게시물에서 `발견된 기업/경쟁사/소재·장비 제조사/협회/제품 규격/전방 고객/부정적 이슈`를 뽑아 재검색. 특히 해외 기업명이 반복되면 한국어 검색을 중단하지 않고 **현지어 원출처로 역추적**한다. 실측 제품별 매출/수주 숫자 발견 시 해당 기업 IR 또는 공식 공시로 연결.
5. **범용 coverage QA**: 결과가 같은 증권사 재인용 10건뿐이면 `소스 편향` 경고. `산업리포트/심층기사, 전문가·채널, 현지 매체·산업협회, 기업/고객 IR·공시, 모순/반론` 중 해당 산업에 중요한 집단을 확인. 각 집단은 `FOUND/SEARCHED_NO_RESULT/ACCESS_BLOCKED/NOT_MATERIAL`과 실제 쿼리·언어·출처 링크를 기록. 특정 PDF 개수나 채널명 강제 금지.
6. **멈춤 판단**: 역할별 신규 기업·매출 상세/반론 발견의 한계 추가가치가 낮아졌을 때만 탐색 중단. 한 번 호출 길이가 모자라면 우선순위 높은 제품 2~4개를 완성형 A/B/C로 출력. 남은 중요한 역할·출처는 명시.

## 발견 즉시 쓸 수 있는 테스트 사례 (정답 하드코딩 금지)

- 전기전자·기판: `대만 PCB 기판 애널리스트 텔레그램`류의 범용 검색에서 메리츠 Tech 채널, Ta Liang/Keyware, TPCA 생산 통계, 중국어 台灣 PCB/IC 載板 업체 자료를 탐색. 이 과정에서 특정 한국 애널리스트의 이름을 입력하지 않아도 발견해야 함.
- 전력기기: `대만 중전기 기업 월매출 / 重電 法說會`에서 華城·士林電機·亞力와 현지 사업별 투자·수주 자료를 탐색. **기판에서 유효했던 전문가 채널만 돌려 쓰면 실패**.
- ESS: 국내 배터리 인뎁스에서 계통·BTM/FTM·인버터·EMS·PCS·셀 분류를 생성하고, 북미/유럽 현지 시장 보고서·셀/통합기업 IR과 고객·수주 검증으로 확장.

## 최소 감사 기록 (내부 문서, 사용자에게 긴 로그 노출 금지)

`role, geography, search_language, query, discovered_author_or_channel, origin_document, source_kind, accessed: title_only|body|blocked, new_company_product_claims, contradictions, verification_followups, why_stop`.
**발견 실패/차단**은 조사 불가이며 해당 산업에 중요한 자료가 없다는 증거가 아니다.
