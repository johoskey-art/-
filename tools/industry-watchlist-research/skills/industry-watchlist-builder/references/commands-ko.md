# 한글 명령 사용법 — Industry Watchlist Builder v0.6

**ChatGPT 입력창에서 `@`를 입력하고 목록에서 실제 `Industry Watchlist Builder`를 선택한 뒤** 아래처럼 자연어로 요청한다. 반드시 정확한 띄어쓰기나 영문 명령을 사용할 필요는 없다. 앱에 플러그인 목록이 노출되지 않거나 연결되지 않으면 채팅에 이름만 입력하는 것으로 호출되지 않을 수 있다.

## 새로 만들기와 수정

| 한글 사용자 명령 | 기존 모드 | 수행할 일 |
|---|---|---|
| `전력기기 관심종목 새로 만들어줘` | NEW | 산업제품 역할 → 글로벌·중소형 피어 → HOME/EVENT → QA |
| `전력기기 관심종목 최신화해줘` | UPDATE | 현재 MASTER를 불러오고 변한 사업/이벤트만 추가 검증 |
| `전력기기 누락기업 검산해줘` | AUDIT | 빠진 전문기업·복수 사업·오분류·종목코드 점검 |
| `전력기기 이벤트 다시 검증해줘` | EVENT AUDIT | 옛 리포트·공식 정책·증권사 반론 비교 |
| `전력기기 뉴스로 모멘텀과 리스크 검증해줘` | NEWS AUDIT | EVENT 중간 뉴스 스트레스 테스트 + 반증·공식 원문 확인 |
| `전력기기 HOME하고 EVENT 목록 보여줘` | RENDER | 기업 중심 피어와 별도의 이벤트 민감주 표시 |
| `삼성증권 관심종목 파일 만들어줘` | EXPORT | 실제 확인된 POP HTS 파일/종목 등록형식만 사용 |
| `한투 관심종목 파일 만들어줘` | EXPORT | 실제 확인된 KIS 파일/종목 등록형식만 사용 |

## 보고서 조사·이어 읽기

| 한글 사용자 명령 | 기존 별칭 | 수행할 일 |
|---|---|---|
| `전력기기 보고서 조사 시작해줘` | CORPUS START ... PRIORITY | 전체 후보 목록, 빈칸과 읽을 순서 설정 |
| `다음 중요한 보고서 읽어줘` | CORPUS NEXT 10 PRIORITY | 미열람 고정보가치 문서 우선, 한 번에 실질 처리 가능한 만큼 |
| `다음 보고서 20개 이어 읽어줘` | CORPUS NEXT 20 PRIORITY | 이전 읽기 기록을 재사용, 중복 피하기 |
| `해외 보고서 위주로 다음 20개 읽어줘` | CORPUS NEXT 20 GLOBAL | 해외 자료를 우선하되 최신·과거 균형 유지 |
| `대학생 리포트 다음 10개 읽어줘` | CORPUS NEXT 10 UNIVERSITY | KUVIC/SMIC/S.T.A.R. 세부 구조·가설 우선, 실적 재검증 |
| `한국IR협의회 보고서 다음 10개 읽어줘` | CORPUS NEXT 10 KIRS | 강소기업·제품별 매출 경로 탐색 |
| `텔레그램 수집 보고서 다음 10개 읽어줘` | CORPUS NEXT 10 TELEGRAM | 원본 PDF 우선, 요약 전재는 PDF 읽기 건수 제외 |
| `읽을 보고서 우선순위 다시 정해줘` | CORPUS RERANK | 새로운 EVENT·기업 정보를 바탕으로 다시 정렬 |
| `조사 진행상황 보여줘` | CORPUS STATUS | 실제 읽은 건수, 남은 상위 10개와 조사 공백 |
| `보고서 조사 마무리 검산해줘` | CORPUS FINALIZE | 건수가 아닌 핵심 공백, 반론, 원문 근거, 뉴스 검증으로 종료 판정 |

## 의미·오류 처리

- `다음` 또는 `이어`는 **마지막으로 저장·재확인된 동일 산업 조사 원장**에서 아직 읽지 않은 후보를 고른다. 원장 확인이 안 되면 기존 내용을 지어내지 말고 읽기 기록 복구 또는 새로운 큐 시작을 명확히 알린다.
- 숫자 20은 **요청량**이다. 20편을 읽지 못했으면 실제 읽은 건수만 보고한다. PDF 본문을 읽지 않았으면 읽은 것으로 기록하지 않는다.
- 사용자가 `뉴스 확인`, `뉴스 검산`, `시장 내러티브 검증`을 요청하면 우선 `news-audit.md` 절차를 수행한다. 현재 산업/이벤트가 명확하면 다시 산업명을 묻지 않는다.
- `전력기기 최신화`, `NEW BTM`, `CORPUS NEXT 10` 등 예전 영어·한영 혼용 방식도 계속 지원한다.
- 명령어는 **스킬이 해석할 자연어 요청**이다. 독립적인 모바일 앱 버튼이나 CLI 명령이 아니다.
