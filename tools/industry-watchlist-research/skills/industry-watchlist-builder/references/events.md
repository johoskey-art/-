# Economics-linked events

Use common event classes: DEMAND, SPEC-UP, BOTTLENECK, PRICE/MIX, SHARE/QUAL, CAPA/RAMP, POLICY/STRUCTURE.

EVENT record must include: description, category, present stage (NARRATIVE→SAMPLE→QUAL→DESIGN WIN→ORDER→CAPA→RAMP→REVENUE→MARGIN), impacted products, companies, Q/P/MIX/SHARE/UTIL/COST/YIELD pathway, next observable indicator, confirming and contradicting signals. Without such a pathway, leave it as a note rather than a core event.

Distinguish **causal physical order** and **observed signal order**, and record direct beneficiary vs upstream/downstream effect vs competitor/substitute. The chain is a hypothesis unless sources support actual supplier-customer relationships. Record end-market units separately from component content-per-unit and inventory pre-build.
