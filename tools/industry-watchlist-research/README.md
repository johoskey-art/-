# Industry Watchlist Builder — ChatGPT plugin source

This folder contains the source for the user's private ChatGPT Industry Watchlist Builder plugin (v0.1.1). It is stored here for version history; the GitHub repository is **not** the ChatGPT plugin installation mechanism.

- Plugin: https://chatgpt.com/plugins/plugins_6ad7f51ac7448191a4b84bf5d859d33e
- Main skill: [SKILL.md](skills/industry-watchlist-builder/SKILL.md)
- Verification script: [validate_master.py](skills/industry-watchlist-builder/scripts/validate_master.py)
- Tests: [test_validator.py](skills/industry-watchlist-builder/tests/test_validator.py)

## Scope
Cross-border industry HOME / peer / EVENT maps, role-based discovery of overlooked companies, independent company/product evidence checking, and broker export only after actual file format and security-search support are confirmed.

## Safety and limitations
This public source includes no Google Drive report text, credentials, portfolio positions, or broker account data. The included sample master is illustrative; script tests validate **structure only**, not listing validity, product claims, or live trading capabilities.

For mobile ChatGPT, the plugin runs according to connected tools and available ChatGPT capabilities. Python validation scripts in this repository are not automatically executed on mobile.
