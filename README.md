# 📈 주가위치분석시스템 (Stock Position Analysis System)

> 과거 대세 주도주들의 저점-고점 등분(5등분·7등분) 평균 및 피보나치 등비 함수식을 역산하여, 미래 종목의 주가 위치(각설이~상투)를 실시간 판별하고 매매 타점을 잡는 퀀트 시스템입니다.

## 🎯 핵심 원리 및 수학적 설계

### 1. 5대 사이클 20개 역대 주도주 실측 데이터
1990년대부터 2020년대까지 한국 증시를 이끈 5대 핵심 산업 사이클의 대세 상승 배수를 실측 검증했습니다.
* **통신·IT 사이클 (1999~2021)**: SK텔레콤(5.00배), 한글과컴퓨터(14.04배), NAVER(23.25배)
* **조선 저번 사이클 (2003~2011)**: 현대미포조선(43.78배), 현대중공업(25.14배), 삼성중공업(10.84배)
* **철강 사이클 (2003~2011)**: 현대제철(21.06배), 동국홀딩스(21.19배), POSCO(5.98배)
* **자동차·차화정 사이클 (2003~2026)**: 기아(37.28배), 현대모비스(21.35배), 롯데케미칼(12.29배), OCI(16.00배)
* **반도체 1~3차 사이클 (1998~2026)**: 삼성전자(12.09배), SK하이닉스(25.81배), 주성엔지니어링(12.88배), 한미반도체(8.56배)
* **전체 산술평균**: **16.53배** (조선·철강·차화정 슈퍼사이클용)
* **전체 기하평균(로그 평균)**: **13.30배** (중앙값 **13.46배**, 표준 권장)

### 2. 주가위치 7단계 정의 (로그-피보나치 등비 배율)
로그 차트($M = 13.30$) 기준으로 무릎을 $300$일 초장기 이평선(또는 이중평활 TMA)으로 고정했을 때의 단계별 배율입니다:
1. **각설이패턴 (바닥권)**: $1.00\text{배}$ (무릎 $\div 2.246$)
2. **발목 (1차 진입/턴어라운드)**: $1.47\text{배}$ (무릎 $\div 1.531$)
3. **무릎 (추세 돌파)**: $2.25\text{배}$ ($300$일 초장기선 중심축 - **핵심 매수 타점**)
4. **허벅지 (본격 시세 분출)**: $3.55\text{배}$ (무릎 $\times 1.581$)
5. **허리 (중간 눌림·지지)**: $5.73\text{배}$ (허벅지 $\times 1.618$ 황금비 - **1차 30% 익절**)
6. **어깨 (분할 매도 구간)**: $8.06\text{배}$ (허리 $\times 1.406$ - **2차 40% 익절**)
7. **상투 (최종 고점 과열권)**: $11.21\sim 13.30\text{배}$ (전체 주도주 평균 고점 도달 - **전량 익절**)

## 🚀 실행 및 사용 가이드

### 1. 인터랙티브 웹 대시보드 실행
* `run_dashboard.bat` 파일을 더블 클릭하거나 터미널에서 다음 명령어를 실행합니다:
```bash
streamlit run app.py
```
* 웹 브라우저에서 종목코드(000660, NVDA 등)를 입력하면 7단계 위치, 잔여 상승 여력, 실시간 캔들스틱 차트, 백테스팅 결과를 한눈에 확인할 수 있습니다.

### 2. 파이썬 백테스팅 모듈
```bash
python backtest.py --ticker 000660 --start 2018-01-01
```

### 3. 트레이딩뷰 (TradingView)
1. `stock_position_system.pine` 코드를 복사합니다.
2. 트레이딩뷰 하단 **Pine 에디터**에 붙여넣고 **차트에 넣기(Add to chart)**를 누릅니다.
3. 차트 화면에서 **`Alt + L`**을 눌러 반드시 **로그(Log) 스케일**을 활성화합니다.

### 4. 키움증권 영웅문4
1. `kiwoom_formulas.txt`의 수식을 복사합니다.
2. 영웅문 차트 우클릭 > **수식관리자** > **기술적지표** > **새로만들기**에 등록합니다.
3. 차트 속성에서 **로그 적용**을 체크합니다.
