## 최신 역산 과제 — 국면별 가변 상투·대상투

**[SK하이닉스 중심 시계열 검증 프로토콜](research/methodology/STATE_DEPENDENT_DYNAMIC_BANDS_20261020.md)**: 상투선·대상투선은 수급·시세국면·시간에 따라 움직일 수 있으며 고정 피보나치 정수비를 강요하지 않는다. 한 회사의 정수패턴 재검증은 중단하고, 38개 로그 평균은 과거 분포 참고값만 유지한다. [SK하이닉스 화면 내 폭 변화 수치](research/results/skh_20261020_dynamic_top_knee_screen_spread_2views.csv).

## 현재 계산 기준

사후 상승 사이클마다 시작가격 `L>0`, 사후 고점가격 `H>L`, `R=H/L`이면

```text
로그 5등분: level_j = L × R^(j/5) ; j=0,1,2,3,4,5
로그 7등분: level_j = L × R^(j/7) ; j=0,1,2,3,4,5,6,7
개별 구간배율: b5 = R^(1/5), b7 = R^(1/7)
집계: 각 사이클 단계값을 먼저 구한 뒤, 같은 j끼리 평균
```

**현재 산술평균, 38개 잠정 사이클(34기업)**: `b5=1.503831710×`, `b7=1.336894306×`.
**가격 품질 이슈 1건(효성 2007)을 추가 제외한 37개**: `b5=1.502861985×`, `b7=1.336240502×`.
8개의 잠정 복원 자료는 공식 KRX 수정주가 독립 대조 전이므로 `PROVISIONAL`. 남은 8개 이상 가격/기간검열 사례는 평균에 포함하지 않습니다.

**이 수치는 모두 과거 저점·고점으로 역산한 사후 통계**이며 당시 주도주 상투 예측값이 아닙니다. [블로거 보존 전사](blog_224280566920.txt)는 저점~고점 5/7분할, 각 단계 기록값, 피보나치 n번째 함수, 엘리어트 시세국면 이동을 언급하지만 로그/선형, 기록 숫자와 적용 공식은 공개하지 않았습니다.

## 구형 대시보드/매매코드는 별도 LEGACY

루트 `app.py`, `backtest.py`, `stock_position_system.pine`, `kiwoom_formulas.txt`, `run_dashboard.bat`는 과거의 **SMA240 × 고정배율** 연구 데모입니다. 이들은 **현재 로그 5·7등분 통계/원작 Fibonacci 공식 구현이 아닙니다**. 차트를 로그축으로 그리는 것과 로그 5·7분할로 가격단계를 계산하는 것은 완전히 다른 일입니다.

원본 블로거의 밴드 생성/엘리어트 이동 공식을 모르는 상태에서 `1.5038` 또는 `1.3369`만 근거로 실제 주식 매수/매도 신호를 자동 생성하도록 코드를 바꾸면 **가짜 원작 재현**이 됩니다. 따라서 매매데모는 폐기/덮어쓰기 대신 LEGACY로 표시하고 연구 알고리즘과 완전히 구분했습니다.
