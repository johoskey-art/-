# 📈 주가위치분석시스템 (Stock Position Analysis System)
### [댕기왕자 공식 모델: 성호전자·삼천당제약·SK하이닉스 실측 기준]

> 과거 역대 대세 주도주들의 저점-고점 5등분·7등분 실측 통계와 피보나치 등비 함수식을 기반으로, 미래 종목의 주가 위치(각설이~울트라상투)를 실시간 판별하고 기계적인 매매 타점을 잡는 퀀트 시스템입니다.

## 📋 댕기왕자 공식 투자 매뉴얼

### 1. 매수 매뉴얼
1. **바닥과 발목에서는 절대 사지 않는다.**
2. 바닥에서 240일 무릎선을 강하게 뚫어내는 순간(**🔴 무릎통과신호 빨간 화살표**) 또는 돌파 후 지지 확인 시 매수한다.
3. 같은 섹터의 친구들까지 함께 무릎을 통과했는지 확인하고 실적 주도주를 공략한다.
4. **늦어도 최대 허벅지선(1.46배)을 통과하기 전까지만 매수 구간으로 본다.** (허벅지 통과 후는 신규 매수 금지)
5. **어깨선(2.85배) 이상까지 우직하게 보유한다.**

### 2. 매도 매뉴얼
* **표준 매도 전략**:
  1. **1차 분할 매도**: **어깨선(초록색)** 도달 시 물량의 **70%를 1차 익절**.
  2. **최종 전량 매도**: 어깨 위 **상투선(얇은검정)**에 도달하거나 **🔵 상투신호 파란 화살표** 발생 시 **잔여 30% 전량 매도**.
  3. **손익 보전**: 어깨 도달 후 조정 시 **허벅지선을 이탈하면 즉시 전량 매도**.
* **각설이 패턴(2차 상투) 예외 규칙**:
  * 1차 상투 치고 내려올 때 **허리선(굵은검정)을 거래량 줄며 지지받고 장대양봉이 나오는 극소수(10% 미만) 실적 주도주**만 2차 상투(쌍고점)를 노리며, 쌍고점 터치 시 미련 없이 전량 탈출.
* **기준선 전이 착시 필터**:
  * 1차 상투 이후 이평선이 따라 올라와 주가 위치가 낮아 보이는 것은 **착시이자 함정**이므로 신규 매수 절대 금지!

## ⚖️ 실제 사례 분석 (케이스 스터디)

1. **삼천당제약 (000250) - 상투 후 수직 낙하 사례**
   * 88,200원 바닥에서 무릎통과신호 발생 ➔ 상투선(1,184,000원) 도달(약 13.4배 상승).
   * 상투선 터치 즉시 파란색 상투신호 발생 후 곧바로 **-68% 수직 낙하**.
   * ➔ *상투에서 전량 매도하지 않으면 계좌가 붕괴된다는 원칙 증명.*

2. **성호전자 (043260) - 울트라상투 광기 분출 사례**
   * 1,030원 바닥에서 무릎통과신호 발생 ➔ 60,000원대 울트라상투까지 **41배 폭등**.
   * 0.1% 미만의 극단적 광기 케이스이지만, 울트라상투는 수학적으로 100% 천정임을 확인.
